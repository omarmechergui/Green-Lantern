
# 🌿 GreenLantern — Waste Management Platform

**Description:**
GreenLantern is an environmental digital project that helps users declare recyclable waste, track points, and exchange them for rewards.
The goal is to encourage eco-friendly behavior in a simple and interactive way.

---

## 🚧 Project Status

* **Frontend:** Mostly ready, but not yet connected to the backend.
* **Backend:** Under development, planned to use Node.js and MongoDB.

---

## 🖥️ Frontend

**Technologies:**

* React
* React Router
* React Icons
* Leaflet (for maps)

**Pages:**

* **Dashboard** — View general statistics
* **DeclareWaste** — Add new waste with type, image, and location
* **WasteHistory** — View past submissions
* **Rewards** — View and redeem points

**To do:**

* User authentication (Login / Register)
* Connect frontend to backend APIs (Axios / Fetch)
* UI/UX improvements and responsive design

---

## ⚙️ Backend

**Planned Technologies:**

* Node.js + Express
* MongoDB (or Firebase)
* JWT Authentication
* Cloudinary / Firebase Storage (for images)

**Next Steps:**

* User registration and login
* Store waste data
* Calculate points and manage rewards
* Handle images and geolocation
